# 10-inch tablet screenshots — driver role

Four native Android captures from an isolated 10-inch tablet emulator (1080 × 1920 pixels, 220 dpi), using synthetic demonstration data. No customer data is included. Images are unedited screen captures.

1. Driver Home
2. Assigned trip details and actions
3. Route manifest and stops
4. Documents and compliance metadata

Each PNG has a 9:16 portrait aspect ratio, both sides between 1080 and 7680 pixels, and file size below 8 MB. Exact sizes are recorded in validation.json.

Extract the accompanying ZIP and upload its four PNG files to the Google Play Console 10-inch tablet screenshots section. No remote upload was performed.
