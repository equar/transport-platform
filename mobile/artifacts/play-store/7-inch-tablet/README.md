# 7-inch tablet screenshots — driver role

Four native Android app captures from an isolated 7-inch tablet emulator, using synthetic demonstration data. No customer data is included. Images are unedited screen captures.

1. Driver Home
2. Assigned trip details and actions
3. Route manifest and stops
4. Documents and compliance metadata

Each PNG is 720 × 1280 pixels (9:16 portrait), with both sides between 320 and 3840 pixels and file size below 8 MB. See validation.json for exact sizes.

Upload the four PNG files to the Google Play Console 7-inch tablet screenshots section. The ZIP is for convenience; extract it before uploading. These files have been prepared locally; no remote upload was performed.
