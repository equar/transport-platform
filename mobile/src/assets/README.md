This directory contains Expo assets used by the app configuration.

The native setup scripts expect the referenced image files to exist so Expo prebuild can run successfully.

`bakaroo-wordmark.png` is the official Bakaroo Transport logo,
shared with `frontend/public/branding/BakarooTransportLogo.png` (2172 × 724, 3:1).
Display with contain sizing on a light backing; do not stretch it into a square.
